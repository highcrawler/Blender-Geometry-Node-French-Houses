# Phase 9F – result

**TECHNICAL RESULT: PASS**

The existing Phase-9D wooden-shingle roof is now implemented as an independent [`roof/wooden_rect.py`](../roof/wooden_rect.py) module with frozen `RoofSpec`, `RoofResult` and `build_rectangular_roof(spec, building_root, building_collection)`. It imports **no Cottage code, IRCSS or installable add-on**. One small [`Cottage adapter`](PHASE9F_COTTAGE_ADAPTER.md) is the first caller; the old body remains geometry/material identical. Every call creates **exactly five roof Mesh objects** (two decks, one combined shingle field, two ridge planks) in an exclusively owned child collection, with a per-house root and private four-slot roof materials. Root-local geometry is independent of world translation/yaw. Implementation and validation rules: [module details](PHASE9F_MODULE_IMPLEMENTATION.md).

[Sixteen-case regression](PHASE9F_REGRESSION.md): all eight Phase-9E configurations × CLEAN/AGED match **complete** historical Phase-9D roof/body SHA-256, triangles, rows, shingle counts, material face slots, saved Phase-9C object/shader inventory and unchanged physical gap/length limits. Same-seed replays and inverse creation order match. Eight true control renders are RGB pixel-identical to 9D; three independently placed houses were saved, reopened and validated in Blender 5.2.2. Injected partial-build errors and invalid ownership/parameters are isolated. Historical experiment files, IRCSS and add-on code were not edited. T06 retains the known 0.10728 m minimum length near the 0.10 m acceptance floor; the skinny eave shadow and simple ridge remain baseline characteristics. This proves the **fixed eight-case matrix**, not all numeric combinations or novel house types.

**Answers:** (1) Yes: the roof module no longer imports or reads Cottage and can be called with its own `RoofSpec` and owner references. (2) Yes: every local roof mesh and face/material assignment matches archived 9C/9D evidence; the new root/collection structure changes only organization. (3) Yes: three separately owned houses with independent Seeds/CLEAN/AGED roof materials, including translation and rotation, were tested; changing B did not change A/C. (4) In principle yes: a future rectangular Barn or Workshop caller can supply a spec/root/collection without copying roof mathematics; neither building nor its integration has yet been built or validated. (5) For add-on integration a separate, bounded caller and registration path would be needed; for single-house GLB export a separately tested owner-aware mesh-collection exporter/adapter must select only this root's body/roof, handle transforms, preserve the Phase-6 **ground-footprint pivot**, check mesh/material completeness and isolate temp export objects. The existing Phase-6 exporter is IRCSS/GN-specific and cannot export these Cottage collections as-is. **No export was implemented in 9F.**

**Exactly one next small development step:** specify and test an owner-scoped, read-only Cottage geometry/pivot collector against the saved three-house scene, before adding any GLB writer or add-on UI.
