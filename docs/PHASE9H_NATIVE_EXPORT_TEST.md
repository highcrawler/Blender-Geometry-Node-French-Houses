# Phase 9H – native Blender export experiment

Blender **5.2.2 LTS**; Godot **4.7.stable.official.5b4e0cb0f**; isolated [`godot_test`](../experiments/native_export_godot_09h/godot_test/project.godot), no Pilgrimm access. Inputs are the immutable 9F [`three_owned_cottages.blend`](../experiments/wooden_roof_system_09f/three_owned_cottages.blend) and Phase-9G read-only collector. Only disposable scene copies are saved. Reproduction: [`README`](../experiments/native_export_godot_09h/README.md).

**Variant A:** [`prepare.py`](../experiments/native_export_godot_09h/prepare.py) invokes `bpy.ops.export_scene.gltf` with native `export_format='GLB'`, `use_selection=True`, `export_yup=True`, `export_apply=False`, `export_materials='EXPORT'`, `export_cameras=False`, `export_lights=False`, `export_extras=True`. The collector validates each owner's exactly 37 source meshes and 14,054/6,818/14,066 source triangles. Select those meshes **and their EMPTY Building_Root**, not other houses or cameras. For B/C, move only the root of the disposable loaded scene to `(0,0,0)` and reset yaw to 0 before selected export, then restore it in memory; no mesh vertex/material changes. This yields a portable ground-pivot-centered individual asset. C's original 0.45-rad yaw is tested independently in the three-house `.blend` import (Godot Y yaw), while its standalone GLB represents the same local geometry without that placement rotation. No glTF writer or mesh merger was written.

**Variant B:** Blender's native Godot `.blend` importer invokes Blender/glTF in background. The default `blender/nodes/active_collection_only=false` imported the *entire* three-house test (112 meshes, 34,950 triangles, plus cameras/lights); it is **not** single-owner isolation. With `blender/nodes/active_collection_only=true`, the explicitly active A/B/C owner collection **includes its nested roof collection** and imports only that owner (37 meshes each). [`active.py`](../experiments/native_export_godot_09h/active.py) saves disposable three-house files with different active collections; selection is per saved `.blend`/view layer, not per Godot instance. The original B/C world translation and C yaw remain in those direct imports. For truly local assets, [`single.py`](../experiments/native_export_godot_09h/single.py) saves isolated one-house B/C copies with their roots normalized; `prepare.py` similarly saves single A. Both methods require a per-asset Blender preparation/copy, unlike a GLB selection for delivery. The saved scene remains the only geometry source. `.blend` import parameters used: `blender/nodes/active_collection_only=true` where noted, `blender/materials/export_materials=1`, `blender/nodes/modifiers=1`, regular Blender→glTF settings; no material conversion or baking. No source modifiers exist.

Godot 4.7's actual EditorSettings key is `filesystem/import/blender/blender_path` (not `blender3_path`). This system uses `/snap/bin/blender`; see optional [`set_blender.gd`](../experiments/native_export_godot_09h/godot_test/set_blender.gd) with `H_BLENDER` override. Initial unset/wrong path made Godot report *Blender path invalid* and blocked `.blend` import; corrected path imported successfully. Initial background RPC connection reported `Unexpected status during RPC connection: 4`, then **fell back to direct `.blend` conversion** and produced working imports; subsequent imports/audits produced no error. This is an environmental warning, not evidence that RPC succeeds. No program installed or upgraded.

The imported [`test_scene.tscn`](../experiments/native_export_godot_09h/godot_test/test_scene.tscn) has both GLB cottages, neutral ground, camera, light and environment. Actual Godot screenshots were captured by [`capture.gd`](../experiments/native_export_godot_09h/godot_test/capture.gd) using identical light/camera settings for four single-asset comparisons; this is not a Blender render. Godot uses OpenGL compatibility for the repeatable test, not a claim about Forward+ or Pilgrimm's render settings. Assets and `.import` settings are kept in the isolated experiment so the test project opens independently; `.godot/` import cache and the disposable `.blend1` backup are ignored.
