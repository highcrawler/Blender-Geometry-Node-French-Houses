# Phase 9G – read-only geometry collector contract

**Public API:** `from building import collect_building_geometry, BuildingGeometryResult, CollectorError`; `collect_building_geometry(building_root: bpy.types.Object, building_collection: bpy.types.Collection) -> BuildingGeometryResult`. No Cottage, roof generator, add-on, exporter or GLB dependency. Source: [`building/collector.py`](../building/collector.py). Accepts Blender object/collection **references**, not names. A returned result holds original ID references, not copied meshes; do not use it after deleting or editing the source scene. Failure raises `CollectorError` with a stable `.code` and human-readable detail, without repair.

A result exposes `building_root`, `building_collection`, `mesh_objects`, `body_objects`, `roof_objects`, `records`, `pivot_local`, `pivot_world`, `world_to_export_local`, total `triangles`, distinct `materials` and `diagnostics`. Each `MeshRecord` holds object/mesh references, role/optional roof part, copies of `matrix_local`, `matrix_world`, computed `export_local_matrix`, triangulation count and `MaterialUsage` per *existing* slot: index, actual material reference, polygon count and triangle count. Unused populated slots remain visible, e.g. CLEAN's fourth roof slot, with 0 assigned polygons/triangles. `mesh_objects` is an exhaustive set represented as a tuple; ordering reflects process-local ID order, not a cross-save stable serialization. Object names in errors/reports are explanatory only. Material assignment respects `Object.material_slots` (including object-level slot links), not material names.

Current validated structural contract: one unparented, unit-scale, finite `EMPTY` root with only Z yaw linked exclusively to one exclusively used owner collection. Body meshes are directly in that collection; exactly one direct child collection contains all and only the roof meshes. All meshes descend from the root by parent links; arbitrary spatial overlap is irrelevant. The existing roof's five `roof_part` tags (`deck` × 2, `shingles` × 1, `ridge` × 2) are checked when present. No fixed body count is encoded; the 32-body/5-roof expectation lives **only** in the Cottage regression fixture. Collections deeper than the current roof child are traversed for stray/ambiguous objects and rejected if incompatible; an eventual alternative owner schema needs explicit contract/tests. Other future roof types may omit `roof_part` entirely but must retain `role='roof'` and an exclusive roof collection. No footprint geometry or L-/U roof inference.

Each source mesh is inspected directly, without creating new data or calling an exporter. Blender's `calc_loop_triangles()` populates a transient mesh triangulation cache; triangles are counted from the actual `loop_triangles`, per triangle's slot. No modifiers, shape keys, constraints or object instancing are accepted: their evaluated output cannot safely be inferred from the unevaluated source without another validated realization contract. Empty/nonfinite/singular meshes or transforms and missing/out-of-range material slots fail. Duplicate object links, foreign parent relationships, shared mesh datablocks or material references with other mesh objects, shared collection hierarchy and missing tagged roof pieces fail instead of being guessed. This conservative ownership check also forbids deliberate cross-building shared materials until a separately specified safe policy exists.

**Transform for a later writer (not executed):** `pivot_local=(0,0,0)` is the documented Cottage supporting-footprint center at ground level, **not computed from roof/decor bounds**. `pivot_world=root.matrix_world @ pivot_local`. Let `W=matrix_world` of a mesh. `world_to_export_local=T(-pivot_local) @ inverse(root.matrix_world)` and `export_local_matrix=world_to_export_local @ W`. Apply `export_local_matrix @ local_vertex` to a *future isolated export copy*, never to source mesh vertices in 9G. For today's unit-scale root, translation and yaw cancel while the ground origin maps to zero. An arbitrary later building's ground pivot is **not inferred**; it needs a separate footprint/pivot contract before using this API.

Not implemented: GLB writing, evaluated modifier/Geometry-Nodes realization, instances, material conversion, temporary export scenes, add-on registration or a new building framework. The IRCSS/Phase-6 exporter uses a different GN ownership/footprint contract and cannot consume these Cottages unmodified.
