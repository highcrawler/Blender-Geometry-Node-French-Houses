All 28 source images are real Blender 5.2.2 Cycles renders (12 samples, denoised). Long/Compact use the **same** orthographic camera position, orientation and scale in the iso/front/side/roof-detail comparisons, and identical lighting; thus the apparent size difference is not masked. The two tightly framed connection views use the *same ortho scale* for each size but target each building's own eave/ridge. Board C uses a disclosed scale of 11.5 for Long and 8.25 for Compact to make both approximately 300 px high; **do not compare physical house sizes using C**. Neither C image is upscaled. Boards A/B reduce all 800×600 source renders by the same factor for layout.

Visual judgment: both roofs retain legible overlapping courses and slightly staggered seams at roughly 300 px; the Compact shingles look somewhat coarser relative to the smaller building but do not overwhelm it. Both sizes show a consistent overhang and roof family in both states. Gable-end close-ups reveal no new open hole; the small irregular shingle edge and simple plank cap match the 9A Long construction. The eave close-up shows a thin dark recess along the deck/shingle junction on Compact, also present on Long; this is a visible baseline simplification rather than a new Compact-only failure. The small gable-edge remainder is not conspicuous at normal scale. AGED remains a desaturated variant of CLEAN; moss is deliberately faint at game distance. Final artistic approval remains with the project lead.
