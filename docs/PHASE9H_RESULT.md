# Phase 9H – native import evaluation result

**TECHNICAL RESULT: PASS** — both routes actually ran through Godot 4.7, geometry/material/pivot were measured independently, and their shared **material fidelity defect** was reproduced rather than concealed. **GLB WORKFLOW: PARTIAL. BLEND WORKFLOW: PARTIAL. RECOMMENDATION: C**, a thin later native-GLB preparation adapter only; **not** a custom glTF writer. [Technical comparison matrix and screenshots](PHASE9H_GODOT_IMPORT_COMPARISON.md) · [native option and Blender-path evidence](PHASE9H_NATIVE_EXPORT_TEST.md) · [decision](PHASE9H_WORKFLOW_DECISION.md) · [reproduction](../experiments/native_export_godot_09h/README.md).

Blender **5.2.2 LTS**, Godot **4.7.stable.official.5b4e0cb0f**. Branch `experiment/native-blender-godot-import-09h`, based exactly on 9G commit `927010f`. Original 9F/9G reference scene, roof, Cottage adapter, collector, addon/exporter and golden geometry were not modified; no Pilgrimm repository touched. An isolated test project, scripts, native exported GLBs, disposable `.blend` copies, real Godot screenshots, import settings, and machine reports exist under [`experiments/native_export_godot_09h/`](../experiments/native_export_godot_09h/).

A/B/C each import as **37** Godot meshes with **14,054 / 6,818 / 14,066** actual triangles on *both* paths, respectively; roof has all five pieces, no foreign geometry when selection/active-owner option is configured. A has 39 used surfaces and 7 used materials, B/C 40 and 8. Roof CLEAN/AGED shader colors, AGED moss tint, 0.92 roughness and 0 metallic survive. **All four procedural Cottage body materials import white** through *both* glTF paths: source Noise→ColorRamp→Principled Base Color is not represented by the imported material's constant albedo. The unused fourth CLEAN roof slot vanishes as an unused exported surface, with no triangle loss. Both routes produced **byte-identical Godot screenshot pairs for A and B** under the same OpenGL lighting/camera, including the defect; screenshots are not Blender renders. Import pivot and meters match after disposable root normalization. Active three-house B/C `.blend` imports retain original offset and C yaw on Godot Y, while normalized single-house files put the root at ground origin. Unchanged `.blend` re-save/reimport and GLB reimport retain an identical complete Godot audit. Godot initial background RPC warning fell back to direct `.blend` import after the Blender executable was configured; with the invalid default path the import had failed.

**Answers:** (1) **Geometry yes, full source-material appearance no**: Blender native GLB and Godot `.blend` both import all Cottage triangles and roof shades, but all body procedural colors turn white. (2) Direct `.blend` is *not* better here: same result plus Blender runtime requirement and active-collection/file-state preparation. Native GLB is the preferred underlying delivery format. (3) CLEAN warm roof and AGED desaturated/moss roof survive; **whole-building** CLEAN/AGED fidelity is PARTIAL due to white bodies. (4) Yes: one source `.blend` can manage multiple houses; selected-object GLBs isolate each, while Godot `active_collection_only=true` includes nested roofs and imports the one **saved active collection**. Importing several houses separately still needs per-owner active-state copies or one-house `.blend` files. (5) A **small preparation adapter is warranted**, not a custom writer: native paths cannot reproduce the current body shader colors; B/C also need repeatable local root normalization. (6) The smallest next step is a single export-copy-only material conversion experiment for A's clay shader with Godot measurement and visual acceptance, before automating all four or adding UI.

**Limits:** no material baking, no texture generation, no exporter integration or add-on changes in this phase; Forward+ visuals, transparency, animations and untested building types remain NOT TESTED. The 4.6-MB asset directory consists of reproducible small GLB/`.blend` fixtures kept so the isolated test project opens without re-exporting; the `.godot` cache and backup files are not committed. This is a measured decision, not proof that every Blender procedural shader survives native conversion. No merge into `main`.
