# Single Checkout Policy

1. `ircss-fork` is the **only active development checkout** of this repository.
2. Use Git branches **inside this checkout**; do not create extra worktrees or clones without the project lead's explicit prior approval.
3. Before switching branches, inspect `git status` (including untracked files). Back up or otherwise preserve uncommitted work; never discard it as a side effect of switching.
4. Keep experiments under this repository's `experiments/` directory, not in sibling development folders.
5. Preserve historical commits, branches, and experiment references; do not merge branches merely to consolidate workspaces.
6. GitHub provides version history. Local folders are **not** separate project versions.

This policy does not authorize deleting existing data, forcing Git operations, or merging into `main`.
